# 1.2 AWS Identity & Access Management (IAM)

# Lab 6: Enable Multi-Factor Authentication (MFA)

> **⏱ Duration:** 15 Minutes
> **📈 Difficulty:** Beginner

---

## 📖 Overview

This lab demonstrates how to enable Multi-Factor Authentication (MFA) for both the AWS root account and an IAM user. MFA adds an additional layer of security by requiring a time-based one-time password (TOTP) in addition to the account password during sign-in.

---

## 🎯 Lab Objectives

By the end of this lab, you will be able to:

* Enable MFA for the AWS root account.
* Configure an authenticator application.
* Enable MFA for an IAM user.
* Verify MFA during the AWS sign-in process.

---

## 📋 Prerequisites

Before you begin, ensure you have:

* An active AWS account.
* Root user credentials.
* The IAM user **`vinod-devops`** created in the previous lab.
* A mobile device capable of running an authenticator application.

> 🔒 **Security Best Practice**
>
> AWS strongly recommends enabling Multi-Factor Authentication (MFA) for **both the root account and all IAM users**, especially those with administrative privileges.

---

# Step 1 – Enable MFA for the Root Account

## 🔐 Configure Root Account MFA

Navigate to:

**Account Name → Security Credentials**

Perform the following steps:

1. Select **Multi-factor authentication (MFA)**.
2. Click **Assign MFA device**.
3. Configure the following:

| Setting         | Value             |
| --------------- | ----------------- |
| MFA Device Name | `root-mfa`        |
| MFA Device Type | Authenticator app |

4. Click **Next**.

---

# Step 2 – Set Up an Authenticator Application

## 📱 Register the MFA Device

Install one of the following authenticator applications on your mobile device:

* Google Authenticator
* Authy

Complete the configuration:

1. In the AWS Management Console, click **Show QR code**.
2. Open the authenticator application.
3. Scan the displayed QR code.
4. Enter **two consecutive 6-digit verification codes** generated by the application.
5. Click **Add MFA**.

> 💡 **Tip**
>
> Keep a secure backup of your authenticator application or recovery codes (if available). Losing access to your MFA device can delay account recovery.

---

# Step 3 – Enable MFA for the IAM User

## 👤 Configure MFA for an IAM User

Navigate to:

**IAM → Users → `vinod-devops` → Security credentials**

Perform the following steps:

1. Select **Multi-factor authentication (MFA)**.
2. Click **Assign MFA device**.
3. Follow the same configuration process used for the root account.

> ℹ️ **Note**
>
> After MFA is enabled, the IAM user must provide a valid MFA code during every sign-in.

---

# Step 4 – Test the MFA Sign-In Process

## ✅ Verify MFA Authentication

Perform the following validation:

1. Sign out of the AWS Management Console.
2. Sign in using the **`vinod-devops`** account.
3. Enter the account password.
4. When prompted, enter the current **6-digit code** from the authenticator application.
5. Click **Sign in**.

> ✅ **Success**
>
> If authentication is successful, MFA has been configured correctly for the IAM user.

---

## 📝 Note

> Enabling MFA significantly improves account security by requiring something you **know** (your password) and something you **have** (your authenticator device). This reduces the risk of unauthorized access, even if account credentials are compromised.
